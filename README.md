# Store Market 🇩🇿

واجهة متجر إلكتروني جزائري متعددة البائعين — نسخة أولية تجريبية.

## الحالة الحالية
- واجهة React + TypeScript + Vite.
- العربية والفرنسية مع دعم اتجاه RTL/LTR.
- تصفح تجريبي للمنتجات والتصنيفات والبحث.
- سلة تجريبية محفوظة محلياً في المتصفح (localStorage).
- صفحات تعريفية لفضاء البائع ولوحة الإدارة.
- لا توجد حتى الآن قاعدة بيانات أو مصادقة أو طلبات حقيقية أو تكامل دفع/توصيل.

## التشغيل المحلي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. نفّذ `npm run dev`.
4. لفحص نسخة الإنتاج نفّذ `npm run build` ثم `npm run preview`.

## النشر على Cloudflare Pages
- اربط مستودع GitHub `Store-market/Store-Market-` بحساب Cloudflare Pages.
- اختر الفرع `store-market-fresh` حتى تتم مراجعة التغييرات قبل دمجها إلى `main`.
- Build command: `npm run build`.
- Build output directory: `dist`.
- Framework preset: `Vite`.
- لا يحتاج هذا الإصدار إلى متغيرات بيئة أو مفاتيح API.
- ملف `public/_redirects` يضمن توجيه مسارات تطبيق الصفحة الواحدة إلى `index.html`.

## قبل إطلاق متجر حقيقي
يجب إضافة backend وقاعدة بيانات دائمة، ومصادقة آمنة وصلاحيات خادمية للمالك والبائع والعميل، وتدفقات طلبات ومخزون حقيقية، ثم اختبارها. لا تفعّل الدفع الإلكتروني أو التوصيل أو ربط Meta قبل إعداد تكامل رسمي واختباره. لا تضع الأسرار أو كلمات المرور في المستودع.

## بيانات العرض
كل المنتجات والأسعار والمتاجر الحالية بيانات توضيحية وليست عروضاً تجارية حقيقية.
